# 拾卷站点插件

点击主窗口右上角的「打开插件目录」。复制 silvernoelle.com.json，改名为新站点的小写域名加 .json，例如 books.example.org.json。匹配时忽略开头的 www.。文件使用 UTF-8。也可以通过「安装插件」选择已编写的 JSON 文件进行安装或更新。未安装匹配插件时会显示「不支持此网站」，从该提示安装后将自动重试。保存后重新解析网址即可生效，当前已载入的目录继续使用解析时的规则。

## 规则字段

|字段|含义|
|---|---|
|version|当前填数字 1。|
|name|界面显示的插件名称。|
|catalog|仅在目录页出现的元素的 CSS 选择器。|
|title|目录页上的书名元素。|
|links|仅选中章节标题链接 a[href]。章节名取链接文字。|
|older|可选。指向下一批目录条目的 a[href]；最后一页应匹配不到。|
|order|document 保留跨页收集顺序，reverse 将整份目录反转。|
|first_page_suffix|可选。目录分页路径末尾的正则表达式。匹配部分替换为 /，以便从中间页回到首页。|
|chapter_title|从独立文章网址导入时使用的标题元素。|
|body|单篇文章的正文容器。|
|remove|可选。从正文容器剔除的元素，可用逗号连接多个选择器。|
|author|可选。当前入口页中包含原作者名字的元素。缺省时可在界面填写。|

先用分类页解析，检查第一篇、最后一篇和条目数。选其中一篇导出，确认正文段落正确且没有侧栏、分享按钮或评论。然后用独立文章网址验证单章导入。规则适用于服务器直接返回目录链接与完整单章正文的 HTML 网站。
