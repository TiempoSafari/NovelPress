# 拾卷站点插件

点击主窗口右上角的「打开插件目录」。复制 silvernoelle.com.json，改名为新站点的小写域名加 .json，例如 books.example.org.json。匹配时忽略开头的 www.。文件使用 UTF-8。也可以通过「安装插件」选择已编写的 JSON 文件进行安装或更新。未安装匹配插件时会显示「不支持此网站」，从该提示安装后将自动重试。保存后重新解析网址即可生效，当前已载入的目录继续使用解析时的规则。

## 规则字段

|字段|含义|
|---|---|
|version|当前填数字 1。|
|name|界面显示的插件名称。|
|catalog|仅在目录页出现的元素的 CSS 选择器。|
|catalog_link|可选。作品详情页的目录链接；如果存在，插件会先打开完整目录页。|
|title|目录页上的书名元素。|
|title_remove|可选。从书名元素中删除的子元素，例如刺猬猫标题里的作者署名。|
|links|仅选中章节标题链接 a[href]。章节名取链接文字。|
|ignore_links|可选。正则表达式；匹配到的链接文字不会作为章节，例如哔哩轻小说目录里的“插图”。|
|older|可选。指向下一批目录条目的 a[href]；最后一页应匹配不到。|
|order|document 保留跨页收集顺序，reverse 将整份目录反转。|
|first_page_suffix|可选。目录分页路径末尾的正则表达式。匹配部分替换为 /，以便从中间页回到首页。|
|chapter_title|从独立文章网址导入时使用的标题元素。|
|cover|可选。作品封面 img 或链接元素；缺省尝试网页分享图。|
|body|单篇文章的正文容器。|
|remove|可选。从正文容器剔除的元素，可用逗号连接多个选择器。|
|author|可选。当前入口页中包含原作者名字的元素。缺省时可在界面填写。|
|chapter_api|可选。站内 JSON 章节列表接口路径，适用于目录由页面脚本加载的网站。与 book_id_pattern、chapter_url 配合使用。|
|book_id_pattern|可选。用于从作品页路径捕获作品 ID 的正则表达式。|
|chapter_url|可选。章节链接路径模板，可使用 {book_id} 与 {chapter_id}。|
|chapter_lock_field|可选。章节 API 返回的付费标记字段；标记为 VIP 的章节会在界面锁定。|

内置解析器包括普通 CSS 规则，以及刺猬猫的 `"parser": "ciweimao"` 正文读取器。刺猬猫解析器只读取站点标记为免费且正常授权的章节；付费章节不会绕过权限。七猫使用目录 API 中的 `is_vip` 字段锁定付费章节。

普通 CSS 规则适用于目录链接和章节正文直接出现在 HTML 中的网站。遇到目录或正文必须由网页脚本读取的站点时，需要为其添加专用解析逻辑，并通过 JSON 规则声明接口和路径。
